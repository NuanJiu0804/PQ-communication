# 基于后量子混合密码的端到端加密即时通讯系统 —— 架构说明

> 后量子安全的端到端加密即时通讯系统。功能对标微信常规能力,密码学对标 Signal 并做后量子混合加固。

## 1. 核心安全不变量

1. **明文与私钥永不离开客户端。** 服务器只做认证、公钥分发、密文中继与暂存、媒体密文存储、元数据统计。
2. **抗 HNDL(Harvest Now, Decrypt Later)。** 握手使用经典 + 后量子**混合**:即使未来量子计算机攻破 X25519,只要 ML-KEM-768 不被攻破,会话密钥仍安全。混合方式为「并接后做 HKDF」——任一组件安全即整体安全。
3. **账号鉴权体系与 E2EE 密钥体系相互独立。** 前者是邮箱/口令/JWT,服务器掌握;后者是身份密钥/预密钥/棘轮,服务器只存公钥部分。
4. **管理后台是「隐私证明」而非「后门」。** 它能看到的,正是抓包能看到的:元数据 + 不可读密文;代码层面没有任何解密路径。

边界声明:元数据(谁、何时、给谁、发了多大密文)对中继服务端必然可见,这是中继型架构的固有属性。系统通过「传输层混合 PQ-TLS + 内容层 E2EE」尽力保护,但不声称元数据匿名。

## 2. 组件与技术栈

| 层 | 选型 | 关键理由 |
|---|---|---|
| 客户端 | Tauri(Rust 核心 + React/TS) | crypto-core 在 Rust 进程,用纯 Rust 原语完成加解密与本地加密存储,私钥不进 JS |
| 后端 | Go(Gin + WebSocket) | 后端不碰 E2EE;并发/长连接强;单二进制跨平台;Go ≥1.24 原生混合 PQ-TLS(X25519MLKEM768) |
| 数据库 | PostgreSQL 16 | 账号/关系/群/预密钥/离线密文 |
| 缓存/实时 | Redis 7 | 在线状态/路由/发布订阅/限流 |
| 对象存储 | MinIO | 加密媒体密文,预签名直传 |
| 客户端密码学 | RustCrypto 纯 Rust(ML-KEM-768 / ML-DSA-65 / X25519 / Ed25519 / XChaCha20-Poly1305 / HKDF)| 免 C 工具链(CMake/OpenSSL),Win/Ubuntu 一致;协议层自行组装,底层算法不自实现 |
| 本地存储 | SQLCipher 同级方案(bundled SQLite + 应用层 XChaCha20-Poly1305)| 全库加密,密钥由用户口令经 Argon2id 派生;避开 Windows 上 SQLCipher 的 OpenSSL 依赖 |

## 3. 密码学设计概要

- **会话建立:混合 PQXDH。** 多次 X25519 DH(IK/EK/SPK/OPK)并接 ML-KEM-768 封装得到的共享秘密,经 HKDF 派生会话根密钥;支持对端离线异步建会话。
- **持续加密:双棘轮(Double Ratchet)。** X25519 DH 棘轮 + 对称键链,提供前向保密与后置入侵恢复;消息用 XChaCha20-Poly1305 AEAD。
- **身份与签名:** Ed25519 + ML-DSA-65 混合签名,用于预密钥签名与身份认证。
- **安全号码:** 对双方身份公钥(经典 + PQ)做域分隔哈希,渲染为可读数字 + 二维码,支持带外核对防 MITM。
- 「全程后量子棘轮」作为可选扩展(P7+),握手始终为完整混合后量子。

## 4. 设备模型

当前为**单设备**(每账号一设备),数据表预留 `device` 维度以便后续扩展为多设备(Sesame 式多会话同步)。

## 5. 分阶段交付

| 阶段 | 内容 |
|---|---|
| P0 | 项目骨架、基础设施编排、后端健康检查、客户端外壳、设计令牌 |
| P1 | 邮箱注册/登录、真实 SMTP 验证码、Argon2id、JWT |
| P2 | 密钥体系 + 单聊 E2EE(PQXDH + 双棘轮 + AEAD + 测试向量)、WS 中继、安全号码 |
| P3 | 离线消息、消息状态/已读/撤回、在线/输入中、SQLCipher 同级本地加密库 |
| P4 | 好友(ID/二维码)、申请/同意/删除/黑名单、资料 |
| P5 | 群聊(成对扇出,Sender Key 可选)、多媒体(客户端先加密再上传密文) |
| P6 | 管理后台:元数据可视化、隐私证明、用户管理、审计日志、RBAC |
| P7 | 混合 PQ-TLS、集成测试、双平台验证、Docker 一键、完整文档、安全自审 |

## 6. 跨平台约定

- 统一 LF 换行(`.gitattributes`);路径用语言标准库 API,不手拼分隔符。
- 后量子与经典原语均为纯 Rust(RustCrypto),无系统库差异;bundled SQLite 用 bundled 特性从源码构建,仅需 C 编译器,免 OpenSSL/SQLCipher 系统库。
- 所有敏感配置走 `.env`,提供 `.env.example`,零硬编码。
- 提供 Docker 一键与非容器本地开发两种方式。
