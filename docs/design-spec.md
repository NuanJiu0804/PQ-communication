# 基于后量子混合密码的端到端加密即时通讯系统 —— 设计规范

> 设计意图:**沉稳 · 技术感 · 值得信赖**。像一款真实的安全通讯产品,而非模板拼凑。

## 0. 明确规避(反「AI 味」)

- ❌ 紫色/靛蓝渐变、彩虹渐变
- ❌ 全局玻璃拟态(毛玻璃滥用)
- ❌ 所有元素一律超大圆角
- ❌ 营销落地页式居中大标题 + emoji 小标题(如「✨ 功能」)
- ❌ 默认 Tailwind 那套毫无个性的外观、滥用阴影与渐变按钮
- ❌ 千篇一律的卡片无脑堆叠

## 1. 配色(浅色 / 深色双主题)

强调色采用**沉静的 teal(蓝绿)**,刻意避开靛紫俗套;底色近中性。

| 角色 | 浅色 | 深色 |
|---|---|---|
| 背景 base | `#FAFAFA` | `#16181D` |
| 背景 surface(卡片/侧栏) | `#FFFFFF` | `#1E2127` |
| 背景 elevated(浮层) | `#FFFFFF` | `#252931` |
| 边框 | `#E4E6EB` | `#2C313A` |
| 文本 主 | `#1A1C20` | `#E8EAED` |
| 文本 次 | `#5A6068` | `#9BA1AC` |
| 文本 弱 | `#8A909A` | `#6B7280` |
| 强调 accent | `#0E7C7B` | `#2AA7A3` |
| 强调 hover | `#0B6463` | `#37BAB5` |
| 成功 | `#2E7D52` | `#4FB07C` |
| 警告 | `#9A6B00` | `#D9A441` |
| 危险 | `#B23A3A` | `#E06C6C` |

状态色一律低饱和,服务于信息而非装饰。

## 2. 字体

- **界面文本:** 人文风无衬线 `IBM Plex Sans`(回退 `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`)。
- **技术信息:** 等宽 `IBM Plex Mono`(回退 `ui-monospace, "Cascadia Code", Consolas, monospace`)。用于指纹、密钥、用户 ID、密文样本、时间戳等。

字号刻度(rem):`0.75 / 0.8125 / 0.875 / 1 / 1.125 / 1.375 / 1.75`。行高正文 1.5,标题 1.25。

## 3. 间距与圆角

- 间距基准 4px:`4 / 8 / 12 / 16 / 24 / 32 / 48`。
- 圆角克制:`sm 4px / md 6px / lg 8px / pill 999px`(仅头像、徽标用 pill)。
- 阴影克制:仅浮层/弹窗用一层柔和阴影,常规卡片用边框区分而非阴影。

## 4. 布局

桌面三栏 IM:

```
┌────────┬───────────────────────┬──────────────┐
│ 导航   │  会话/消息时间线        │  会话详情     │
│ 会话列表│                        │ (资料/成员/   │
│        │  输入区                 │  安全号码)    │
└────────┴───────────────────────┴──────────────┘
```

信息密度贴近真实 IM,不留营销式大块留白。

## 5. 状态(必须全部处理)

每个交互元素都要覆盖:`default / hover / active / focus-visible / disabled`;
每个数据视图都要覆盖:`empty / loading / error / success`。

- focus 用 2px accent 描边(`outline`),不可移除可访问性焦点。
- 加载用克制的骨架屏或细进度条,不用花哨 spinner。
- 空状态给一句说明 + 一个明确的下一步操作。

## 6. 图标

`lucide-react`,线性图标,克制使用;同一视图内尺寸统一(16/18/20)。

## 7. 设计令牌落地

所有以上数值以 CSS 变量形式集中定义于客户端 `src/styles/tokens.css`,浅/深主题通过 `:root` 与 `[data-theme="dark"]` 切换,组件只引用变量、不写死颜色,保证全局一致。
